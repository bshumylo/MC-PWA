# Security policy

## Supported versions

Only the latest release of MC PWA receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private
[security advisory form](https://github.com/bshumylo/MC-PWA/security/advisories/new) instead, and include the
EspoCRM and PHP versions, the extension version and the steps to reproduce.

You can expect an acknowledgement within a few days. A fix is released as a new version; the advisory is published
after users have had time to update.
